- 🧠 **Machine Learning & Data:** Python, NumPy, Pandas, Scikit-learn, data cleaning, ETL pipelines, data validation, and model pipelines.
- 🔥 **Deep Learning:** PyTorch, neural networks, MLPs, backpropagation, CNNs, and image classification experiments.
- 🤖 **Generative AI:** LLMs, prompt engineering and evaluation, LoRA/PEFT fine-tuning exercises, text generation, GANs, and diffusion models.
- 📚 **RAG & AI Agents:** Document RAG, embeddings, vector search, retrieval evaluation, LangChain, function calling, and multi-agent workflows with CrewAI.
- ⚙️ **Backend & Deployment:** FastAPI, REST APIs, asynchronous Python, Streamlit, MySQL, Docker, and GitHub Actions CI/CD.
- 📊 **MLOps & Observability:** MLflow experiment tracking, LangSmith tracing, structured logging, Prometheus, and Grafana.
- 🚀 **Hands-on Projects:** LLM chatbot API, RAG pipeline, local-LLM SQL agent, CNN image classification, and ML experiment tracking.
